# Rita Awuor Otieno — Portfolio

Static HTML portfolio. Run locally with `npm start` and open the address printed by `http-server` (or open `index.html` directly). The featured project previews use iframes to load the live websites, so a browser or hosting policy that blocks framing may show an empty preview; the direct live-site buttons remain available.

## Project details and audit notes

- Metameta Children’s Home: HTML, CSS and JavaScript site with Firebase Authentication and Realtime Database code, plus separate Firebase Cloud Functions. Its repository notes that database rules, contact behavior and donation/payment flow still require review; the portfolio does not imply those flows are production-ready.
- Vineyard Children’s Home: HTML, CSS and JavaScript site with Firebase Authentication, Cloud Firestore, Cloud Storage and an administrator dashboard. Firebase configuration and deployment must be completed for the features to run.
- The calculator is linked as a repository only. The old portfolio did not establish a working live demo, so functionality should be confirmed before presenting it as a completed project.

The original homepage contained unverified client testimonials, project counts, skills and a generated text file presented as a CV. These were removed from the refreshed homepage. No actual CV PDF was identified; `assets/images/Self-declaration-form.pdf` is not represented as a CV. The old blog page still contains sample tutorial content and should be reviewed or unpublished before linking it from navigation. Confirm the preferred professional title, education/certification details, phone number and availability before restoring them to public pages.
